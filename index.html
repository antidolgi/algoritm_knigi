Книголюб — Вологда

🎯 ОСНОВНЫЕ ПРАВИЛА

  1. Минимальный ценник: 1100₽ (от него считаем скидку 45%)
  2. Формула: Ценник - 45% = Цена продажи
  3. Средняя цена считается только по книгам с одинаковой обложкой
  4. Электронные версии — НЕ учитываются
  5. Уцененные товары — НЕ учитываются, ЕСЛИ наша идеальная, ЕСЛИ Наша плохая, ТО учитываются
  6. Нет в наличии — учитываются с пометкой, но не как основной ориентир

Дополнительно: Еще бывают что стоят книги в средний ценник например 1200-1400 и одна стоит за 7800 на нее мы тоже не обращаем внимания.

Факторы влияющие на цены: Автографы авторов +30-40%

📋 ПОШАГОВЫЙ АЛГОРИТМ

ШАГ 1: ИДЕНТИФИКАЦИЯ КНИГИ

Собрать данные:

  • Название
  • Автор
  • ISBN
  • Год издания
  • Издательство
  • Тип обложки (твердая/мягкая)
  • Состояние (идеальное/хорошее/с дефектами)
  • Есть ли дефекты (подчеркивания, пятна, порванные страницы, плесень и т.д.)

ШАГ 2: ПОИСК АНАЛОГОВ НА OZON

Приоритет 1: Поиск по названию + автор

  • Фильтр: только печатные книги (исключить электронные)
  • Фильтр: только с одинаковой обложкой

Приоритет 2: Если точного совпадения нет → поиск по ISBN

Приоритет 3: Если на Ozon нет → поиск на других площадках (Яндекс.Маркет, WB, букинистические сайты)

ШАГ 3: АНАЛИЗ КОНКУРЕНТОВ

Собрать все цены на книги с одинаковой обложкой:

Пример:
- Книга А: 600₽ (в наличии)
- Книга Б: 800₽ (в наличии)
- Книга В: 1700₽ (в наличии)
- Книга Г: 186₽ (электронная) → ИСКЛЮЧИТЬ
- Книга Д: 1929₽ (уцененная) → ИСКЛЮЧИТЬ

Рассчитать:

  • Среднюю цену
  • Диапазон (мин-макс)
  • Количество предложений

ШАГ 4: ОПРЕДЕЛЕНИЕ БАЗОВОЙ ЦЕНЫ

Базовая цена = Средняя цена конкурентов с одинаковой обложкой

Если средняя цена < 1100₽ → Базовая цена = 1100₽ (минимальный ценник)

ШАГ 5: КОРРЕКТИРОВКА ЦЕНЫ

Применить корректировки к базовой цене:

ПОВЫШАЮЩИЕ КОЭФФИЦИЕНТЫ:

ФакторКорректировка
Нет в наличии у конкурентов+20-30%
Нет конкуренции на Ozon (наша книга единственная)+30-50%
Твердая обложка (у конкурентов мягкая)+10-20%
Редкое/антикварное издание+20-50%
Идеальное состояние (букинистика как новая)+10-20%
Цена на других сайтах выше+10-20%

ПОНИЖАЮЩИЕ КОЭФФИЦИЕНТЫ:

ФакторКорректировка
Книга бу (не новая)-10-20%
Есть дефекты (подчеркивания, пятна)-10-30%
Много дешевых аналогов на рынкеИспользовать минимальный ценник 1100₽
Мягкая обложка (у конкурентов твердая)-10-20%
Популярная книга, много предложений-10-20% от средней

ШАГ 6: ПРИМЕНЕНИЕ МИНИМАЛЬНОГО ЦЕННИКА

Если расчетная цена < 1100₽:
Ценник = 1100₽
Цена продажи = 1100 - 45% = 605₽

ШАГ 7: ФИНАЛЬНАЯ ПРОВЕРКА

Правила:

  1. Цена продажи не должна превышать самую дорогую книгу с такой же обложкой на рынке (если нет уникальных преимуществ)
  2. Цена должна быть конкурентной (не дороже средней по рынку более чем на 20%)
  3. Если книга бу → цена должна быть ниже новой

💻 Псевдокод для программиста

def calculate_book_price(book_data):
    # ШАГ 1: Идентификация
    title = book_data['title']
    author = book_data['author']
    isbn = book_data['isbn']
    year = book_data['year']
    cover_type = book_data['cover_type']  # 'hard' или 'soft'
    condition = book_data['condition']  # 'perfect', 'good', 'defects'
    defects = book_data.get('defects', [])
    
    # ШАГ 2: Поиск аналогов на Ozon
    competitors = search_ozon(title, author, isbn)
    
    # Фильтрация
    competitors = [c for c in competitors if c['type'] == 'print']  # Только печатные
    competitors = [c for c in competitors if c['cover'] == book_data['cover']]  # Одинаковая обложка
    competitors = [c for c in competitors if not c['discounted']]  # Исключить уцененные
    
    # ШАГ 3: Анализ конкурентов
    if len(competitors) == 0:
        # Нет конкурентов на Ozon
        base_price = 1100  # Минимальный ценник
        no_competition = True
    else:
        prices = [c['price'] for c in competitors]
        base_price = sum(prices) / len(prices)
        no_competition = False
    
    # ШАГ 4: Минимальный ценник
    if base_price < 1100:
        base_price = 1100
    
    # ШАГ 5: Корректировки
    adjustment = 0
    
    # Повышающие
    if no_competition:
        adjustment += 0.40  # +40%
    
    if all(c['available'] == False for c in competitors):
        adjustment += 0.25  # +25% (нет в наличии)
    
    if cover_type == 'hard' and any(c['cover_type'] == 'soft' for c in competitors):
        adjustment += 0.15  # +15% (твердая vs мягкая)
    
    if year < 1990:  # Антикварная
        adjustment += 0.30  # +30%
    
    if condition == 'perfect':
        adjustment += 0.15  # +15%
    
    # Понижающие
    if condition == 'used':  # Бу
        adjustment -= 0.15  # -15%
    
    if len(defects) > 0:
        adjustment -= 0.20 * len(defects)  # -20% за каждый дефект
    
    if len(competitors) > 10 and base_price < 1000:
        # Много дешевых аналогов
        final_price = 1100  # Минимальный ценник
    else:
        final_price = base_price * (1 + adjustment)
    
    # ШАГ 6: Финальная проверка
    if final_price < 1100:
        final_price = 1100
    
    # Не превышать самую дорогую книгу с такой же обложкой более чем на 20%
    if competitors:
        max_competitor_price = max(c['price'] for c in competitors)
        if final_price > max_competitor_price * 1.20:
            final_price = max_competitor_price * 1.20
    
    # ШАГ 7: Расчет цены продажи
    sale_price = final_price * 0.55  # -45%
    
    return {
        'listing_price': round(final_price, -10),  # Округлить до 10
        'sale_price': round(sale_price, -10),
        'discount': '45%',
        'reasoning': generate_reasoning(adjustment, competitors)
    }

  3. Посмотри цены конкурентов (исключи электронные и уцененные)
  4. Рассчитай среднюю цену
  5. Примени корректировки:
    • Нет конкуренции? → +30-40%
    • Есть дефекты? → -20%
    • Книга бу? → -15%
    • Твердая обложка? → +15%
  6. Проверь минимальный ценник: если < 1100₽ → ставь 1100₽
  7. Рассчитай цену продажи: Ценник - 45%

Пример расчета:

  • Средняя цена конкурентов: 800₽
  • Нет конкуренции: +40% → 1120₽
  • Минимальный ценник: 1100₽ → берем 1400₽ (чуть выше)
  • Цена продажи: 1400 - 45% = 770₽
